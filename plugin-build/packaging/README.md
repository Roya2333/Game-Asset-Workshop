# 管理工坊 · 通用本地插件

版本：0.5.1。面向独立游戏开发者和小型团队，使用 GPT 创作并管理策划、人物、道具、技能、UI 图片和对白等素材。

本包只有插件程序、界面、图标、使用说明和安装助手；不包含任何游戏项目、测试素材、聊天记录、账号密钥、配音参考声音、TTS 模型或开发者本机配置。

## 安装前

- Windows 10/11；本版安装助手和 TTS 一键部署面向 Windows。
- 使用支持本地插件与本地执行的桌面宿主。本包按 Codex 桌面本地插件方式安装；普通 ChatGPT 网页端不能直接运行本地插件包。
- Node.js 22 或更新版本。安装助手优先使用已安装的 Node，也支持桌面运行环境自带的 Node。缺少时请从 https://nodejs.org/ 安装。
- 文字和图片生成使用宿主可用的 GPT 能力。没有相应账号权限或图片工具时，插件本身不能提供这些模型能力。

## 安装与开始

1. 先把 ZIP 完整解压，进入 `narrative-studio` 文件夹，不要在压缩包预览中直接运行。
2. 双击 `安装管理工坊.cmd`。助手会把程序复制到当前 Windows 用户的本地应用目录，配置本机 Node 路径并安装插件。不会修改其他插件，也不创建游戏项目。
3. 重启桌面应用，在本地聊天中启用「管理工坊」，发送“打开管理工坊”。
4. 首次打开创建你自己的项目，填写项目名称并选择保存位置；字段可以留空。以后让 GPT 读取设定、生成内容和真实图片，保存后在插件里审核确认。

插件程序与项目索引位于 `%LOCALAPPDATA%\ManagementStudio`。游戏资料保存在你创建项目时选择的文件夹；升级插件不会把别人的资料带进来。

## 人物配音

不使用配音时，无需安装 TTS。需要配音时，在人物页上传或录制自己的参考声音，点击“一键部署 TTS 2.5”，环境会部署到所选项目的 `本地TTS` 文件夹。部署需要联网下载依赖和数 GB 模型；实际速度取决于电脑、网络及 GPU 环境。

人物配音采用本地 IndexTTS 2.5。音乐、环境音及技能/道具音效目前提供设计和已有文件管理，尚不提供真实音效文件生成服务。

## 手动安装

如果宿主提供“从本地文件夹安装插件”，选择解压后的 `narrative-studio` 文件夹。本包同时提供便携格式 `plugin.json` / `mcp.json` 及兼容配置 `.codex-plugin/plugin.json` / `.mcp.json`。手动方式需要 `node` 在宿主可访问的 PATH 中。

安装助手可检查环境而不安装：在本文件夹运行 `node install.mjs --check`。

## 试用与反馈

建议先验证：创建空白项目 → 填写设定 → 创建道具或人物 → 生成一张图片 → 确认 → 保存并重开 → 导出交付包。反馈问题时附上插件版本、所在板块、操作步骤和报错截图；无需发送账号密钥或整个项目。

插件界面版本为 0.5.1；本包已在独立目录验证空白启动、27 个工具发现、资料读写和界面资源读取。不同电脑的桌面插件接入、麦克风权限、GPU/TTS 部署及 PSD 软件兼容性仍需在对应环境试用。
